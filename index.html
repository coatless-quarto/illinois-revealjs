Home

The illinois-revealjs extension gives Quarto’s reveal.js format an unofficial Illinois-inspired theme.

The demo slides are the template.qmd that quarto use template gives you, rendered with the current theme (source).

Installing

To start a new presentation, run this in an empty folder:

quarto use template coatless-quarto/illinois-revealjs

This will install the extension and create an example qmd file that you can use as a starting place for your presentation slides.

To add the theme to a project you already have, run:

quarto add coatless-quarto/illinois-revealjs

Using

Once the extension is installed, set the format inside of the document header to illinois-revealjs:

---
title: A title
subtitle: A subtitle
format:
  illinois-revealjs: default
author:
  - name: Your Name
    orcid: 0000-0000-0000-0000
    email: alias@email.com
    affiliations: Your Institution
date: last-modified
---

Any other reveal.js feature in Quarto goes under the illinois-revealjs format. For example, the chalkboard feature:

format:
  illinois-revealjs:
    chalkboard: true

What the theme sets

The format builds on Quarto’s default reveal.js theme and adds:

Setting Value
Logo the Illinois block I, at the bottom right of every slide
Slide numbers on
Date format long, such as May 25, 2023
Fonts Fira Sans for text, Fira Code for code
Title slide title, subtitle, author and date in dark slate, #1A292C
Rules a thin orange line, #EB811B, under the subtitle and under section titles
Links Illinois orange, #E84A27
Background #FAFAFA

The logo, slide numbers and date format can be changed in the document header like any other reveal.js option. The fonts and colors come from the theme’s stylesheet, _extensions/illinois/imtheme.scss.

Developer Notes

We created the quarto extension for the revealjs format by using:

quarto create extension format:revealjs

From there, we incorporated a modified version of the Beamer Metropolis that was ported into a Quarto theme by Patrick Schratz (Post).

This site lives in docs/, which .quartoignore keeps out of the files quarto use template copies. When it builds, the workflow copies _extensions/, template.qmd and the title slide image in from the repository root, so the demo always shows the theme as it is on main.
